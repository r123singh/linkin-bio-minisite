# Link-in-Bio Demo Sites

This repository contains three demo Link-in-Bio sites designed for different audiences:

1. 🎨 **Demo 1: Influencer/Content Creator**
   - Soft, pastel design
   - Instagram-style layout
   - Located in `/demo1-influencer`

2. 👨‍💻 **Demo 2: Developer/Designer**
   - Dark mode theme
   - Code-style fonts
   - Located in `/demo2-developer`

3. 🧘 **Demo 3: Fitness Coach**
   - Health-focused colors
   - Testimonials section
   - Located in `/demo3-coach`

## Quick Start

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm start
   ```

3. Visit the demos:
   - Influencer Demo: http://localhost:3000/demo1-influencer
   - Developer Demo: http://localhost:3000/demo2-developer
   - Fitness Coach Demo: http://localhost:3000/demo3-coach

## Customization

Each demo is built with:
- Clean HTML5
- Modern CSS (variables, flexbox)
- Mobile-responsive design
- Optimized for performance

To customize:
1. Edit the HTML files in each demo directory
2. Modify the CSS variables in the `<style>` section
3. Replace the profile images (currently using Unsplash placeholders)
4. Update the links and social media handles

## Features

- 🎨 Custom color schemes for each niche
- 📱 Fully responsive design
- 🚀 Fast loading (no JavaScript required)
- 💅 Hover animations and effects
- 🖼 Profile image support
- 🔗 Social media links
- 📊 Clean, organized code
